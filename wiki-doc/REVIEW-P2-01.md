Пределы приёмки: граф описывает опубликованные факты и консервативное влияние,
не выполняет SQL. Неизвестные runtime-цели и сигнатуры не разрешаются догадкой.
Архивные диапазоны CTE могут указывать начало оператора INSERT, а не строку FROM;
это явно обозначенные operation anchors, полный SQL доступен по той же ссылке.
Обычный CLI выводит полный форматированный JSON и может быть многословным.
Query проверяет целостность исторического комплекта, не повторяет содержательную
приёмку произвольного текста. При конкурентном изменении требуется повтор запроса.
