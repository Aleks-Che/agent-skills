# Проверка выполнения P2-05 — 2026-09-19

Сверены план, статус, код и инструкции. Подробно проверен последний закрытый
пункт P2-05 и регрессия предыдущих этапов. Исходный набор проходил:
689 passed, 1 skipped, 216 subtests passed. Однако новые проверки реального
CLI, файловой системы и процессов воспроизвели ошибки, не покрытые этим набором.

## Найдено и исправлено

1. **Read-only операции записывали журнал.** CLI `publish prepare`, успешный
   и неуспешный `publish publish --dry-run`, а также gate без `--write-decision`
   создавали `.wiki-doc/journal.jsonl`, иногда вместе с отсутствующей wiki.
   Теперь эти пути не пишут в wiki. Флаги `--dry-run`/`--cleanup-run` отклоняются
   для prepare/recover, вместо молчаливого выполнения операции с записью.
2. **Журнал не связывал события одного запуска.** Результаты publisher/gate
   не имели ожидаемых верхнеуровневых `run_id`/`page_id`. Генерировался случайный
   run_id для каждого события; recovery возвращает список и вообще не попадал
   в журнал. Теперь идентичность берётся из manifest/decision или восстановленной
   транзакции, отдельно создаётся `event_id`. Отсутствующий run_id остаётся null.
   Публикация фиксирует идемпотентность; идентичность читается до cleanup.
3. **Конкурентные записи повреждали JSONL.** Три процесса с длинными Unicode-
   событиями воспроизводили перемешивание записей. Запись сериализована общей
   межпроцессной блокировкой, выполняет flush/fsync. Оборванный хвост отделяется
   от следующего события; чтение пропускает повреждённые JSON и UTF-8 строки.
   Ошибка диагностики по-прежнему не меняет результат gate/publisher.
4. **Редкий отказ Windows-пути воспроизведён детерминированно.** В Python 3.12
   `ntpath.realpath` может сохранить префикс `\\?\`, если замена файла между
   двумя системными проверками приводит к ошибке второй проверки. `inside`
   ошибочно отвергал такой эквивалентный путь как `Path escapes wiki: index.md`.
   Теперь сравниваются эквивалентные пространства имён уже разрешённых DOS/UNC-
   путей. Проверка внешнего пути сохранена. Это подтверждённый механизм отказа;
   без трассы прежнего единичного сбоя нельзя утверждать его точную причину.
5. **Новые инструкции отсутствовали в изолированном runtime и хэше manifest.**
   `docs/concurrent-mode.md` и `docs/answer-templates.md` теперь копируются вместе
   с матрицей диалектов и участвуют в `skill_md_sha256`. Тесты изоляции и изменения
   контрольных сумм расширены.
6. **Документация завышала гарантии и путала журналы.** Одиночная публикация
   тоже берёт lock; recovery откатывает незавершённые транзакции по отдельным
   JSON-журналам. Уточнены фактические точки записи диагностического JSONL,
   границы параллельного чтения и ручного редактирования. Шаблоны больше не
   добавляют второе `.md`, не выдумывают период метрик и число ручных блоков,
   различают ready и состоявшуюся публикацию. Удалена недоказанная версия 0.9.0
   из CHANGELOG; сохранена история этапов до версионирования.
7. **Приёмка CLI была слишком узкой.** Добавлены 17 тестов и 8 подслучаев:
   реальное делегирование inventory/plan/coverage/gate/publish из другого cwd,
   отказ после изменения SQL, отсутствие записей в wiki для read-only путей,
   действительная идентичность событий, аварийное завершение и recovery,
   отказ журнала, конкурентная запись, повреждённый хвост и Windows-пути.
   Старые 27 тестов сохранены; тест случайного run_id заменён проверкой event_id.
8. **Статус противоречил сам себе.** В конце P2-05 оставался «не начат».
   Текущий итог отделён от исторических результатов; план и статус согласованы.
   В историческом снимке плана убрана битая ссылка на отсутствующий doc-evaluator.md.

## Воспроизведение

Из каталога пакета `wiki-doc/wiki-doc`, с Python 3.12 и зависимостями requirements.txt:

```text
python -B -m pytest tests -q -p no:cacheprovider
python -B scripts/wiki_doc.py regression --mode reference --output <new_workspace> --repeats 3
python -B scripts/wiki_doc.py regression --mode saved --output <same_workspace> --repeats 3
python -B scripts/regression_mutations.py <workspace>/regression-report.json --expected-root examples/expected --output <new_mutation_dir>
python -B scripts/regression_publish.py <workspace>/regression-report.json --wiki <new_isolated_wiki>
python -B scripts/wiki_doc.py metrics <wiki> --json --mutation-results <mutation_dir>/mutation-report.json
```

Использован `C:/Users/Aleks/AppData/Local/Programs/Python/Python312/python.exe`.
Запуск не требует ручного PYTHONPATH; дочерним процессам передан
`PYTHONDONTWRITEBYTECODE=1`. Существовавшие до проверки изменения отслеживаемых
pyc сохранены, глобальные настройки и зависимости не изменялись.

## Статус и границы результата

P2-05 закрыт после исправлений; незавершённых пунктов P0–P2 в рамках принятого
плана нет. Проверка reference/saved полуавтоматическая; полный LLM-цикл не
запускался. SQL разбирался статически, без БД. Нулевой false-ready относится к
