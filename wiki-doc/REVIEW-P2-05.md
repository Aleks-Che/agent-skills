## Воспроизведение

Из каталога пакета `wiki-doc/` относительно этого отчёта, с установленными
`requirements.txt` и pytest 9.0.3:

```text
python -B -m pytest tests/ -q -p no:cacheprovider --junitxml=../.runtime/p2-05-acceptance-tests.xml
python -B scripts/run_regression.py --mode reference --output ../.runtime/p2-05-acceptance --repeats 3
python -B scripts/regression_mutations.py ../.runtime/p2-05-acceptance/regression-report.json --expected-root examples/expected --output ../.runtime/p2-05-acceptance-mutations
python -B scripts/regression_publish.py ../.runtime/p2-05-acceptance/regression-report.json --wiki ../.runtime/p2-05-acceptance-wiki
```

Для повторного запуска выбери новые выходные каталоги. Мутации выполняются до
публикации, поскольку публикация дополняет исходные комплекты publication plan.
Файлы пакета должны оставаться неизменными между генерацией и приёмкой:
комплекты привязаны к хэшам инструментов. Подробные runtime-отчёты локальные и
игнорируются Git; их пути и хэши указаны в сохранённом acceptance JSON.

## Границы результата

Reference/saved cycle полуавтоматический. Полный LLM writer и серверы СУБД не
запускались. Регрессионный harness использует основные скрипты; сама обёртка
проверена отдельно тестами CLI. Произвольный текст требует независимой
содержательной проверки, которую механическая приёмка не заменяет.

Журнал этапов фиксирует явно включённые вызовы CLI после разбора её аргументов.
Ручная работа writer подтверждается артефактами. Для строго read-only режима
журнал нужно отключить или хранить вне проверяемой wiki; вне `.tmp` он переживает
cleanup. Ошибка финальной записи журнала не отменяет уже выполненную публикацию,
что явно описано в [инструкции](wiki-doc/docs/operations.md).
