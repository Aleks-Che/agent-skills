# 07 — динамический SQL

Вход: 07_dynamic_sql.sql + context.sql.

- Объект документации demo.fn_dynamic(text) идентифицируется однозначно.
- Два EXECUTE: сначала TRUNCATE, затем INSERT в одну динамически именуемую таблицу.
- Источник второго оператора demo_src.events известен статически.
- Шаблон цели demo_stg.events_<p_suffix>; конкретное имя без значения аргумента неизвестно.
- %I применяется ко всему идентификатору таблицы через 'events_' || p_suffix.
- Не добавлять вымышленные partitions и DDL. Описать предел статического анализа.
- Честно описанная динамика не равна неподтверждённому конкретному имени.
