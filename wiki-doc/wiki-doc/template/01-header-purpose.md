# Блок 01 — объект и назначение

Извлеки тип объекта из CREATE/ALTER, а не из RETURNS void или имени файла.
Слой указывай только при подтверждённом соглашении проекта.
Не приписывай KPI, очередь или периодичность по сходству с примером.

Форма результата:

```markdown
# <схема.имя> (<тип объекта>)

**Схема:** <подтверждённая схема>
**Тип:** <table/view/function/procedure/migration/...>
**Диалект и версия:** <из проекта; неизвестную версию обозначить>
**Слой:** <если применим>
**Исходники:** <ссылки>

## Назначение

### Техническое назначение
<Что создаёт, читает, изменяет или возвращает объект>

### Бизнес-назначение
<Подтверждённое описание с источником; интерпретацию обозначить>
```

В конце страницы метаданные происхождения должны позволять установить, по какой
ревизии получено описание. Бизнес-назначение, неизвестное из исходников, так и отметь.
